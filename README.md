# Графический сценарный редактор - Stable Branch

Итоговый продукт в рамках дисциплины "Технологии Программирования" - Web-Приложение для создания и редактирования сценариев в графовом виде.

## Запуск
### Установка
Необходим установленный в системе пакетный менеджер `uv`.

Ниже описана последовательность действий для установки проекта:
```
git clone https://github.com/FiveStarHotel/StableBranch.git
cd StableBranch
uv sync
```

### Запуск сервера
Ниже описана последовательность действий для запуска сервера:
```
uv run uvicorn main:app --reload
```

## Программный стек
- Backend: `FastAPI`
- Работа с БД: `SQLAlchemy` + `Alembic` + `MySQL`
- Менеджер Python зависимостей: `uv`
- Frontend: `React` + `Vite`
